# 🎮 GAMING WORLD - RIFA GAMER

Sistema de rifa com 50 números, tema neon/cyberpunk para a comunidade GAMING WORLD.

## 🚀 Funcionalidades

- ✅ 50 números numerados com ícones gamers
- ✅ Compra de números com nickname
- ✅ Painel administrativo com sorteio
- ✅ Roleta animada para sortear ganhador
- ✅ Design neon/cyberpunk
- ✅ Sistema de reset da rifa
